Lớp 1 · Mật khẩu

Argon2id — không bao giờ lưu plaintext

// backend/src/auth/auth.service.ts:64
const passwordHash = await argon2.hash(dto.password, {
  type: argon2.argon2id,        // đạt chuẩn Password Hashing Competition
  memoryCost: 19456,           // ≈19MB — chống crack bằng GPU/FPGA
  timeCost: 2,
  parallelism: 1,
});
const ok = await argon2.verify(user.passwordHash, dto.password);
Argon2id

Thuật toán hash được cộng đồng bảo mật khuyến nghị hàng đầu hiện nay

LK

Sai email hoặc sai mật khẩu đều trả Invalid email or password — chống dò tài khoản (user enumeration)

Salt

Argon2 tự tạo salt random cho từng mật khẩu — 2 tài khoản cùng mật khẩu cho 2 hash khác nhau

Lớp 2 · Phiên đăng nhập

Access + Refresh token bảo vệ đa lớp

Access token · 15 phút

JWT ngắn hạn xác thực từng request — rò rỉ cũng chỉ dùng được trong thời gian ngắn

Refresh token · 30 ngày

Chỉ dùng để xin token mới — không lưu plaintext trong DB, chỉ lưu SHA-256 hash

Rotation

Mỗi lần refresh, token cũ bị thu hồi ngay lập tức — token bị đánh cắp dùng lại là vô hiệu

Tamper-proof

JWT ký bằng secret từ env, kiểm tra issuer/audience — không sửa được thông tin trong token

Thời gian sống: access 15p, refresh 30 ngày — cân bằng giữa trải nghiệm & bảo mật

Lớp 3 · Cookie

Cookie an toàn trước XSS

// backend/src/auth/auth.controller.ts:31
res.cookie(ACCESS_COOKIE, r.accessToken, {
  httpOnly: true,   // JS client không đọc được → kẻ XSS không cướp được token
  sameSite: 'lax', // trình duyệt không gửi kèm request chéo site
  secure,           // production: chỉ gửi qua HTTPS
  path: '/',
  maxAge: 15 * 60 * 1000,
});
✓
httpOnly — chặn đánh cắp session bằng XSS/script
✓
SameSite=Lax — lá chắn CSRF tầng trình duyệt
✓
Secure — không lọt token khi dùng HTTP
Lớp 4 · CSRF

Chống giả mạo request chéo site

// backend/src/common/guards/csrf.guard.ts
if (SAFE_METHODS.has(request.method)) return true;  // GET/HEAD/OPTIONS
// Với POST/PATCH/DELETE đang có session:
const cookie = cookies.csrf_token;
const header = request.header('x-csrf-token');
if (!cookie || !header || !sameValue(cookie, header))
  throw new ForbiddenException('CSRF validation failed');

function sameValue(a, b) { // so bằng hằng số thời gian
  return a.length === b.length && timingSafeEqual(a, b);
}
✓
Double-submit cookie: server so header với cookie — website thứ 3 không đọc được cookie nên không giả được header
✓
timingSafeEqual — so sánh chuỗi không rò thông tin bằng thời gian phản hồi
Lớp 5 · Trình duyệt

Security headers + Content-Security-Policy

Headers

X-Content-Type-Options: nosniff · X-Frame-Options: DENY (chống clickjacking)

Referrer-Policy: no-referrer · Permissions-Policy tắt camera/mic/geo

Cache-Control: no-store (page nhạy cảm) · HSTS ở production

CSP production
default-src 'self';
object-src 'none';   // chặn plugin
frame-ancestors 'none'; // chặn iframe ngoài
base-uri 'self';
script-src 'self';   // chặn inline/remote script

Không cho unsafe-inline/unsafe-eval ở production → tấn công XSS không chạy được code

Lớp 7 · Input validation

Từ chối dữ liệu bẩn ngay ở biên giới

// backend/src/main.ts:15
app.useGlobalPipes(new ValidationPipe({
  whitelist: true,            // bỏ field không khai báo trong DTO

Lớp 8 · Môi trường phát triển

Khóa endpoint nội bộ của dev server

Next.js dev có các route nội bộ /__nextjs_* (mở Node inspector) — được xử lý trước cả middleware thường, nên bị chặn ở lớp HTTP bằng custom server:

// frontend/server.js — chạy trước khi Next xử lý request
createServer(function (req, res) {
  if (dev && req.url.startsWith('/__nextjs')) {
    res.statusCode = 403; res.end('Forbidden');
    return;
  }
  handle(req, res);
})
✓
Scanner dò sẽ nhận 403 thay vì URL debugger
✓
CSP dev nới unsafe-inline/eval để tiện XHR/HMR — nhưng production thì bỏ hẳn
Lớp 9 · Triển khai

Vững vàng khi lên mạng

CORS allow-list

Production chỉ chấp nhận origin HTTPS với regex từ CORS_ORIGIN — server từ chối khởi động nếu không cấu hình

HSTS

Strict-Transport-Security bắt buộc HTTPS trong production

Secrets qua env

JWT secret, database, storage đều từ biến môi trường — không hardcode, không commit vào git

Storage riêng

Hóa đơn PDF lưu S3-compatible (MinIO local / Cloudflare R2 prod) — tách khỏi app, chống quá tải
